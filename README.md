GPTpy — Générateur de texte avec l’API OpenAI

`gptpy` est un script Python permettant d’interagir avec l'API OpenAI (GPT-3.5/4) en ligne de commande pour générer du texte automatiquement. Ce projet sert de démonstration de l’utilisation d’une API d’intelligence artificielle dans un environnement simple.

Fonctionnalités

- Envoi de requêtes à l’API GPT via la ligne de commande
- Personnalisation du prompt utilisateur
- Réception et affichage de la réponse générée
- Clé API protégée via un fichier `.env`

---

Technologies utilisées

- Python 3.x
- [OpenAI Python SDK](https://pypi.org/project/openai/)
- `dotenv` pour sécuriser la clé API
